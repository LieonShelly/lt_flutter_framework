# 更新 Shell 脚本文档 Skill

当 `shell/bin/` 目录下的 Dart 脚本文件发生变更（新增或修改）时，自动分析脚本内容并更新 `shell/README.md` 文档。

## 触发条件

- `shell/bin/*.dart` 文件被创建或编辑

## 执行步骤

### 1. 扫描所有脚本

读取 `shell/bin/` 目录下的所有 `.dart` 文件，提取每个脚本的以下信息：

- **脚本文件名**（如 `setup.dart`）
- **功能描述**：从脚本中的 `print` 语句、注释或 `_printHelp` 函数中提取
- **命令行参数**：从 `ArgParser` 的 `addOption` / `addFlag` 定义中提取
- **使用示例**：从 `_printHelp` 函数或注释中提取

### 2. 对比现有文档

读取 `shell/README.md`，检查：

- 是否有新脚本尚未在文档中记录
- 已有脚本的参数或功能是否发生了变化

### 3. 更新 README.md

按照以下格式更新 `shell/README.md` 中的「可用脚本」章节：

- 保持现有文档的整体结构和风格不变
- 脚本按编号排列，新脚本追加到列表末尾
- 每个脚本的文档包含：功能说明、使用方法（含代码示例）、输出示例
- 如果脚本支持 `--help` 参数，在使用方法中包含帮助命令
- 如果脚本支持 `--package` / `-p` 参数，说明支持针对单个包操作
- 同步更新「常见工作流」章节（如果新脚本适用于常见工作流）
- 同步更新 Makefile 命令章节（如果 Makefile 中有对应的 make target）
- 文档语言使用中文（与现有文档保持一致）

### 4. 验证

确保更新后的 README.md：

- Markdown 格式正确
- 代码块语法正确
- 脚本编号连续
- 没有遗漏任何 `shell/bin/` 下的脚本
