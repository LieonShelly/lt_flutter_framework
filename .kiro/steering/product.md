# Product Overview

This is **Little Thing** (lt_app), a Flutter-based enterprise mobile application built as a monorepo. The app is a personal reflection and journaling platform with the following core capabilities:

- **Daily Reflection**: Users receive a daily question and submit written answers
- **Thread View**: Browse historical questions and answers in a threaded list
- **Calendar View**: Visual calendar showing reflection activity over time
- **Answer Detail**: View and interact with individual answer entries
- **AI Copilot**: AI-powered assistant for guided reflection
- **Wallet**: Digital wallet with transaction history and market ticker
- **Booking**: Appointment or session booking functionality
- **Shop**: In-app shop/store feature
- **User Profile**: Account management and settings

The project also contains secondary apps: `compass_app`, `shop_app`, `algorithm_app` (learning/reference), and `answer_detail_module` (standalone Flutter module for iOS XCFramework integration).

Primary language in code comments and documentation is Chinese (Simplified).
